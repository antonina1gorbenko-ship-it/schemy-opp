# Схеми ОПП

Структура сайту:

- `index.html` — головна сторінка «Схеми ОПП»
- `profosvita/` — ОПП «Професійна освіта. Цифрові технології»
- `ist/` — ОПП «Інформаційні системи та технології»
- у кожній папці — 2023, 2024, 2025, 2026

Для заміни сторінки року просто завантажте готовий HTML-файл як `index.html` у відповідну папку року.
